# Retrieval Routes

| Task | Read first | Then read if needed |
|---|---|---|
| New session or orientation | [[START]], [[00-System/Memory Core]], [[00-System/Source of Truth]] | [[90-Indexes/Vault Map]] |
| Active work or status | Linear issue/project | Relevant [[01-Projects/README|project]] or [[02-Areas/README|area]] note |

## Rule

Routes are starting points, not authority. Current verified evidence and explicit user instruction win.
