# Query Workflow

Use this when answering questions from Memory Vault.

## Process

1. Identify whether the question asks for active status, durable memory, or source-derived knowledge.
2. Use [[00-System/Retrieval Routes]].
3. Read the smallest relevant note set.
4. Cite internal notes and raw sources when source-derived.
5. Mark uncertainty, age, and conflicts.

## Reusable Synthesis

If a query creates a useful synthesis, save it under [[10-Wiki/Analysis/README|Analysis]] and update [[10-Wiki/index]] plus [[10-Wiki/log]].
