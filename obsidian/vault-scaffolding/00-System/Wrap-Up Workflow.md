# Wrap-Up Workflow

Use wrap-ups to preserve meaningful sessions without creating transcript sprawl.

## Trigger

Write a wrap-up only when:

- the user explicitly asks to save, remember, wrap up, or close out
- meaningful project state changed
- a durable decision or lesson was created
- a source ingest or analysis should be retrievable later

Do not wrap up trivial chats.

## Destination

- Durable session summary: [[30-Archive/README]]
- Project state: relevant [[01-Projects/README|project note]]
- Decision: [[03-Decisions/_index]]
- Lesson: [[04-Lessons/_index]]
- Active follow-up: Linear
- SOP change: `ai-config`

## Summary Shape

Use [[80-Templates/session-summary]].

Keep summaries short, specific, dated, and linked.
