# Strategy Awareness

Strategy awareness is current-state governance, not a chat memory dump.

## Where It Lives

- Global durable operating preferences: only with explicit user confirmation.
- Project strategy: relevant [[01-Projects/README|project note]].
- Area strategy: relevant [[02-Areas/README|area note]].
- Active execution: Linear.

## Useful Sections

Use these when a project or area needs strategic state:

- North Star
- Current Focus
- Audience or customer
- Active offers, products, or workstreams
- Don't-Do List
- Decisions Log
- Customer Insights
- Market Signals
- Hypotheses
- Wins
- Open Questions
- Archive

## Capture Rule

Do not auto-update strategy from casual conversation. Surface a proposed update and apply it only when the user confirms or when the session explicitly includes durable closeout.
