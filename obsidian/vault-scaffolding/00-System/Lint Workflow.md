# Lint Workflow

Use linting to keep the vault useful.

## Checks

- Broken wikilinks
- Visible isolated operating notes
- Raw sources missing from [[20-Raw/sources]]
- Wiki notes missing source links
- Duplicate concepts or entities
- Stale current-state notes
- Active tasks buried in vault prose instead of Linear
- Strategy entries that conflict with Don't-Do lists
- Lessons that should become checks, scripts, project notes, decisions, or no action
- Outside content promoted without passing [[00-System/Fresh Start Policy]]

## Output

Record meaningful findings in [[40-Observability/recommendations]], [[40-Observability/stale-memory]], or [[40-Observability/repeated-work]].

Run [[00-System/Health Check]] for executable coverage.
