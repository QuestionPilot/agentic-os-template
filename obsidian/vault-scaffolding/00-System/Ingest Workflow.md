# Ingest Workflow

Use this for articles, PDFs, transcripts, videos, docs, and other source material.

## Steps

1. Put immutable source material in `20-Raw/Inbox/` or link it from [[20-Raw/sources]].
2. Record the source in [[20-Raw/sources]].
3. If the source will be queried repeatedly, create or update the relevant [[00-System/Data Readiness|data-readiness]] silver platter before broad analysis.
4. Distill source-derived notes into [[10-Wiki/README]].
5. Update [[10-Wiki/index]] and [[10-Wiki/log]].
6. Promote only confirmed durable decisions or lessons into [[03-Decisions/_index]] or [[04-Lessons/_index]].

## Rule

Raw sources are evidence, not memory. Wiki notes are compiled interpretation, not confirmed project truth unless a project/decision note says so.

Large or messy sources should usually pass through a prep artifact first. Agents should read the silver platter unless raw evidence is needed to verify a claim.
