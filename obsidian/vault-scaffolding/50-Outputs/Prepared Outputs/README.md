# Prepared Outputs

Store curated source-derived summaries here when they support repeated reasoning, briefs, decisions, or project work.

Prepared outputs should cite their sources and state their consumer. If there is no consumer, treat the file as data theater and review whether it should exist.

Do not store raw sensitive exports here.
