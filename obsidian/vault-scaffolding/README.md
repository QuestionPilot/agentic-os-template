# Memory Vault

Memory Vault is the durable memory and knowledge core for the Agentic OS.

It is not the active task tracker and not the operating-framework repo. Use it for confirmed project memory, decisions, lessons, source-derived wiki notes, session summaries, and system health notes.

## Source Boundaries

- [[00-System/Source of Truth|Source of Truth]] defines what belongs here versus `ai-config`, Linear, project repos, and local harness files.
- [[00-System/Fresh Start Policy|Fresh Start Policy]] protects this vault from outside-memory sprawl.
- [[START|START]] is the first note for any agent or human using this vault.
- [[90-Indexes/Vault Map|Vault Map]] is the navigation hub.
- [[10-Wiki/index|Wiki Index]] is the catalog for source-derived knowledge.
- [[20-Raw/sources|Raw Sources]] tracks source intake.
- [[00-System/Dream Review|Dream Review]] is the manual-first self-improvement pass.

## Operating Rule

Keep the vault small, linked, current, and source-aware. Prefer one durable note that changes future behavior over many transcript-like notes that nobody will retrieve.
