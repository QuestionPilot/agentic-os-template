# Raw Sources

Raw sources are immutable or minimally processed inputs.

Use [[20-Raw/sources]] as the manifest.

## Folders

- `Inbox/` - new material not yet distilled
- `Processed/` - material already represented in the wiki
- `Assets/` - supporting images, PDFs, screenshots, and attachments

## Rule

Do not treat raw source text as confirmed memory. Distill it through [[00-System/Ingest Workflow]].
