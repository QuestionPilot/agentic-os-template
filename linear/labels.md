# Linear Labels

The standard label set for an agentic-OS Linear workspace. A new workspace should
create all of these; agents apply them per the definitions below.

## Type

- `Feature` — a new capability or surface
- `Improvement` — a refinement of something that already exists
- `Bug` — a defect or regression

## Operations

- `ai-ops` — Agentic OS operations and framework setup work
- `lesson` — a captured lesson pending self-improvement classification
- `follow-up` — a deferred action that remains active after a workstream
- `blocked-tool` — blocked by a missing, stale, or broken tool or capability
- `verification-gap` — verification was weak, skipped, or needs strengthening
- `process-improvement` — improves how the agentic OS itself operates
- `agent-drift` — context or instruction drift, or a stale-memory issue
- `security-review` — needs independent security or secrets review
- `deploy` — deploy, publish, or release-gated work
- `documentation` — docs or operating-rule changes
