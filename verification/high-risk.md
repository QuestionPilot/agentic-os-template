# High-Risk Verification

Use for auth, billing, permissions, secrets, payments, migrations, infrastructure, or production data.

## Proof

- Use current official documentation for the high-risk system.
- Run least-privilege, environment-appropriate checks.
- Add independent review when the blast radius is meaningful.
- Prefer end-to-end proof where practical.
- Avoid printing secrets or storing secret-bearing artifacts.

## Closeout

State the risk surface, proof run, independent review result, skipped checks, and residual risk.
