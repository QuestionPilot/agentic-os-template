# Deploy And Live Verification

Use when pushed, deployed, or live state matters.

## Proof

- Confirm the intended commit, build, or version is deployed.
- Run live smoke checks for the changed surface.
- Check console errors, failed requests, or obvious customer-visible breakage when relevant.
- Know the rollback or recovery path when risk is high.
