# Deploy Certification

Use this playbook when changes are published or live state matters.

## Proof

- Confirm the intended commit or build is deployed.
- Run live smoke checks for the changed surface.
- Check for console errors, failed requests, or obvious customer-visible breakage when relevant.
- Record rollback or recovery path if risk is high.

## Closeout

State whether the result is local-only, pushed, deployed, or live-certified.
