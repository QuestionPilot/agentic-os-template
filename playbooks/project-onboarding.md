# Project Onboarding

Use this playbook when an agent starts work in a new or unfamiliar project.

## Steps

1. Read local project instructions.
2. Identify the active task in Linear or the active-work ledger.
3. Read only relevant long-term notes from Obsidian or the durable vault.
4. Identify stack, commands, verification gates, and deploy rules.
5. Confirm source-of-truth boundaries before changing files.

## Output

Produce a concise orientation summary and the smallest useful next step.
