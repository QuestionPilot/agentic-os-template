# GitHub Housekeeping

Use this playbook for repository hygiene, privacy, branch, artifact, and configuration cleanup.

## Checks

- Confirm repository visibility and default branch.
- Confirm clean or intentionally dirty worktree.
- Scan for secrets and forbidden artifacts.
- Review ignored local state.
- Confirm commit identity policy for the environment.
- Run project validation before commit or push.

## Closeout

- State what was removed or changed.
- State validation performed.
- Create follow-up active-work items for unresolved cleanup.
- Promote durable lessons through `core/self-improvement.md`.
