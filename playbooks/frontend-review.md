# Frontend Review

Use this playbook for frontend UI, UX, accessibility, and rendered-quality work.

## Checks

- Inspect rendered desktop and mobile states.
- Check text fit, spacing, hierarchy, overflow, and interaction states.
- Run accessibility checks when relevant.
- Prefer real screenshots or real product surfaces over fabricated UI proof.

## Closeout

Name browser checks, viewport coverage, accessibility result, and any residual visual risk.
